# RAG Lab

A production-style project for learning and implementing different Retrieval-Augmented Generation (RAG) architectures.

## Planned RAG Patterns

- Simple RAG
- RAG with Memory
- HyDE
- Adaptive RAG
- Corrective RAG
- Self-RAG
- Agentic RAG
- Multimodal RAG
- Graph RAG

## Tech Stack

- Python
- FastAPI
- LangChain
- LangGraph
- React
- Vector Database
- LLM APIs
